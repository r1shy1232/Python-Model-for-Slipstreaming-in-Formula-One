# Python-Model-for-Slipstreaming-in-Formula-One
Python pipeline accompanying *Slipstreaming in Formula One*. Uses FastF1 telemetry from 2021 and 2022 to identify close-following cases, compare them with clean-air performance, and estimate slipstream drag reduction and downforce loss. Uses NumPy, pandas and SciPy. Telemetry is not included.
